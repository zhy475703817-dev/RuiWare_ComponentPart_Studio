# 已发布零部件模型预览

用户要求完成组件平台对应的发布包消费任务，按已讨论方案直接实施。

- 只修改组件平台，保留当前未提交工作，沿用现有 FastAPI / React / Three.js，不添加 CAD 或压缩依赖。
- 点击发布记录触发预览，不修改组件文档、不增加装配成员。加入装配与接口坐标解析后续单独实现。
- FastAPI 通过固定 public 元数据/下载路径读取指定发布记录；校验包字节大小、SHA-256、manifest 模板标识和版本支持。ZIP 不解压到磁盘；限制压缩/解压大小、条目数、JSON 大小、路径和重复条目。
- 新格式使用 outputs.json STL artifact 的 packagePath（固定 geometry/preview.stl）、size、sha256，校验后返回模型。
- 旧格式仅允许从同一配置上游的固定 /artifacts/<hash>/preview.stl 路径读取且核对 artifact SHA-256；缺少或失效时提示旧包需重新发布。不修改、不重新编译历史版本。
- GET /api/published-templates/{id}/preview 返回固定版本引用、单位/坐标、参数/接口定义、模型 URL/大小/哈希/来源。GET /api/published-templates/{id}/preview/model?sha256=... 返回对应模型，版本不符拒绝返回。
- 使用有内存上限的成功结果缓存，以发布 ID 和包哈希为键，后端重启清空；缓存命中仍核对当前上游发布元数据。下载总超时 30 秒，单包/模型 64 MiB，ZIP 总展开 128 MiB / 256 条目 / 单 JSON 2 MiB，缓存最多 128 MiB。
- 前端请求可取消且防止旧响应覆盖新选择；使用 STLLoader 解析有限且非退化的三角网格，切换/新建/卸载释放资源。原点、毫米和右手 Z 向上保持；根据边界调整相机和网格，不修改几何。
- 加载、失败、重试、加载成功明确呈现；详情折叠独立于预览选择。
- 验收包含新包、旧包、坏包、来源边界、缓存/并发、失败后重试及快速切换测试。真实库若仍只有无模型旧包，实际展示其错误，使用隔离测试数据验证成功路径，不向真实共享库添加测试发布。
