# MCP 与共享组件草稿

用户已确认网页与 MCP 共享同一份草稿，并授权实施。

现有 FastAPI 增加官方 Python MCP SDK 的 Streamable HTTP `/mcp` 入口；REST 与 MCP 调用同一组件服务。SQLite 持久化草稿，草稿具有 `draftId`、`document`、`checks`。每次编辑携带 `expectedRevision`，事务内检查并保存，冲突返回 `REVISION_CONFLICT` 和最新草稿，不自动重放旧修改。

后端成为编辑、验证、导出的权威实现；前端保留纯领域函数作为兼容行为和即时编辑投影，服务端返回结果覆盖投影。测试对比两种语言在相同文档上的行为，防止迁移偏差。网页保存当前草稿标识，支持通过 `?draft=<id>` 打开指定草稿；通过草稿列表选择 AI 创建的草稿。网页串行保存编辑，保存期间不轮询覆盖本地输入；失败保留未保存输入，要求显式重读最新草稿或重试，冲突不自动覆盖。

工具覆盖发布库查询、发布详情、参数/接口/STL 预览描述、草稿创建/列表/读取、定义/参数/规则/已有成员编辑与删除、连接记录、接口继承、验证和 JSON 导出。提供结构化输入、结果和错误；不注册尚未实现的装配求解、规则执行、几何重建、正式发布、从发布包加入装配。模型返回固定版本的绝对 HTTP URL，不传大段 STL。

发布库服务和预览缓存复用。搜索声明仅覆盖上游最近最多 1000 条。上游密钥不对调用方暴露；可选 `COMPONENT_MCP_TOKEN` 仅保护 MCP，未配置时限本机使用。远程部署须同时对网页/REST 配置访问控制；本版不新增多用户体系。

SQLite 默认位于被忽略的 `.runtime/components.sqlite3`，可配置 `COMPONENT_DRAFT_DB`。MCP 配置独立于上游密钥。测试使用临时数据库，不污染用户草稿。

验收：协议初始化与工具发现可用；MCP 修改后 REST 读取相同草稿；旧修订不可覆盖新值；后端重建后草稿仍存在；网页保留快速输入、处理冲突和恢复读取；现有测试及构建通过。
