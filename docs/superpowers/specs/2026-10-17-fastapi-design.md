# FastAPI 后端接入设计

用户已批准 React + FastAPI 前后端分离方案并要求实施。

- 保留七阶段前端和 `/api/published-templates` 响应契约，删除 Node 业务代理。
- FastAPI 监听本机 8020，Vite 开发及预览监听 5180 并转发 `/api`；密钥仅由 Python 读取。
- Python 后端按配置、发布库、应用入口分模块。httpx 异步读取固定上游路径，10 秒超时，不跟随重定向，不将上游内部错误或密钥返回客户端。
- 配置读取根目录 `.env`、`.env.local`，系统环境变量优先。默认上游 8010。
- 提供 `/api/health` 和 FastAPI `/docs`、`/openapi.json`，发布列表采用响应模型及数据校验。
- FastAPI 可服务已构建 dist 页面，用于同源本机运行；纯静态部署仍需将 `/api` 转发至 Python 后端。
- 一键启动为项目创建独立 Python 虚拟环境并安装依赖，后台启动后端和前端并检查就绪；失败显示日志，不打开无效页面。
- 不新增数据库、账号系统、包解析、模型加载或正式发布功能。

验收：后端测试覆盖代理契约、错误映射、超时、重定向、配置优先级和文档；保留领域及前端测试；构建通过；浏览器通过 FastAPI 读取真实发布库并保留七阶段交互。
