# FastAPI Implementation Plan

**Goal:** 将发布库业务接口从 Vite 中间件迁到独立 FastAPI 后端。
**Architecture:** React → Vite `/api` 转发 → FastAPI → 零部件平台，生产构建可由 FastAPI 同源提供。
**Tech Stack:** Python 3.12、FastAPI、Uvicorn、httpx、python-dotenv，现有 React / TypeScript。
**Spec:** `docs/superpowers/specs/2026-10-17-fastapi-design.md`

## 约束

保留当前工作区；不提交现有改动。密钥不进入前端或响应。默认端口 5180 / 8020 / 8010。不新增尚未使用的数据库或服务层。按已批准设计在当前会话直接执行。
