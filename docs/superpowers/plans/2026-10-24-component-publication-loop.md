# 组件发布复用闭环

范围：组件草稿发布为不可变版本 → 与零部件一起显示在左侧 → 作为一个固定版本成员加入另一草稿 → 再次发布。中间建模阶段尚未完成，允许空结构版本用于接通链路，保存真实检查结果，不声明工程验证通过。

1. 在现有 SQLite 持久库保存发布元数据、草稿快照、检查结果及 ZIP 组件包；修订校验、同修订幂等、各草稿独立递增版本。
2. 保留原零部件只读接口，新增组件发布列表、详情、下载及发布接口；组件成员仅引用已经存在的不可变发布版本，引用图因此无法形成环。
3. 左侧并行读取两类来源，组件结构版本不走零件模型过滤；一种来源异常不影响另一种成功结果。
4. 显式加入成员，公开接口和参数复制到独立实例，固定发布 ID、版本与校验值，不展开子组件内部结构。
5. 前后端测试、构建和隔离浏览器闭环验证。

当前组件发布存储属于本组件平台后端，随 `COMPONENT_DRAFT_DB` 持久化，不声称已同步 MinIO。未来共享存储接入和装配建模不包含在本次范围内。
