# 用户优先与 Agent 差异提示

用户已选择：空闲时自动同步并展示差异；编辑冲突时用户优先。参考模板平台的 WorkspaceShell、useDraftWorkspace、draftSyncChannel，复用本项目现有同步通道，不增加端口或依赖。

1. 后端在 SQLite 同一事务内记录每次修改的来源、修订、时间和字段前后值。MCP 来源固定为 agent，网页固定为 user，不接受客户端自报来源。
2. 用户提交过期修订时，仅当所有中间修订均来自 Agent，才将用户动作应用于最新文档。这样同字段用户优先，不同字段保留双方。其他用户窗口冲突、缺失历史、重置动作仍拒绝覆盖。目标或引用已删除时保留网页输入并明确提示，允许下载本地副本。
3. 草稿响应携带最近 50 条变更与截断标志；网页按已确认修订过滤并累积 Agent 变更。保存响应同样携带中间 Agent 修改，避免保存竞态丢掉提示。差异面板展示来源、时间、修订、中文字段、修改前后及用户优先说明，可关闭；其他网页的修改不得标成 Agent。
4. 前端保持串行保存和编辑期间禁止轮询覆盖。Agent 修改不再要求用户放弃输入；结构冲突/其他用户窗口冲突继续保留输入，提供下载副本与显式重读。

验证：后端测试覆盖两种写入顺序、多个 Agent 修订、其他网页写入、缺失历史、结构删除、持久化差异、幂等无变更；前端测试覆盖空闲同步、保存响应带差异、迟到轮询、连续提示、关闭、草稿切换和冲突保留。最后运行全量现有测试、构建及真实浏览器与 MCP/REST 交互。
