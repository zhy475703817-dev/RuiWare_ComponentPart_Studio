# 组件尺寸驱动的几何联动

参数阶段的「几何联动」是实际外形修改入口。先读取当前实际尺寸，输入目标 X/Y/Z，输入稳定 650 ms 后自动试算。查看变更后点击「应用」，才会写入草稿；取消、失败和选择候选均不改变原模型。原有参数与实际模型的差异单独显示，加载旧草稿不会按名称增加尺寸绑定或重新移动成员。

## 几何与求解

- `resize_geometry.py` 使用固定发布版本的模板、材料和实例参数执行模板规则及 OCCT 重建。模型、接口定位和测量使用同一参数集。
- 精确外形以变换后的实体执行 `BRepBndLib.AddOptimal`。反算中的凸包和参数小幅试算只是加速估计，不能直接通过验收；最终重新生成全部候选 CAD 并测量。
- 接口通过语义面来源、特征规则和特征实例定位。标准薄壁挤出端面可从来源操作的唯一真实平面恢复；缺少定位来源、多个来源或接口消失会拒绝使用该接口。不会以三维高亮用的包围盒中心代替安装点。
- 优先使用已配置的连接、占用槽位、保存的联动关系及锁定。唯一重合的接口、具有特征来源且共轴的孔位和真实接触面可以构成几何关系；有间隙但没有特征证据、同等候选和未连接的成员需要用户确认。接触面在最终 CAD 中裁剪后检查，避免用已被加工切掉的旧面通过验收。
- 几何关系不写入 `assembly.mates`，也不表示兼容契约、承载或焊接校核通过。
- 只改变模板开放的用户输入尺寸。参数的上下限、整数及离散规格、模板可执行规则和已有绑定共同约束结果。无几何影响、未公开、无有限范围的参数不作为自由驱动量。
- 先尝试只改变影响外边界的参数；例如立柱加高且原孔列仍有效时，可只延长立柱。其他情况使用 SciPy `least_squares(method="trf")`，优先保留无关参数、原有对称、落地、平行及装配平面关系。有限离散规格组合逐一重建，多种通过的规格提供选项。
- 长宽高为组件坐标系 X/Y/Z 的实际外形。水平中心和最低 Z 保持原位置，原有结构分支和方向不翻转。
- 默认外形误差 ≤ 0.1 mm、连接点/轴线距离 ≤ 0.05 mm、方向误差 ≤ 0.1°。可在模板接口 `referenceFrame.geometryTolerances` 中声明 `dimensionMm`、`positionMm`、`angleDegrees`，只接受比默认更严格的正数。位置使用向量距离复核，角度使用实际夹角复核。

局部算法不保证穷举任意结构的全部解。无法收敛、超时或剩余误差过大均返回「本次未找到满足条件的结果」，不会宣称结构绝对不可实现。当前资源上限为 16 层、150 个叶子实例、256 个变量、64 组离散组合及 600 秒求解时间；单次 CAD 内核调用结束后检查取消状态。

## 多层实例和保存结构

启用后文档为 `component-1.1`，发布包为 `component-package-1.1`；原 1.0 文档和发布包仍可读。

- `geometryDesign` 保存版本、坐标轴、基准、锁定、关系、实际尺寸、接口局部坐标快照、来源和验证摘要。
- `ComponentMember.instanceDocument` 保存本实例的完整子组件结果，各层分别保存自己的几何设计。所有约束展开到叶子路径后统一求解，跨层端口映射回具体叶子接口。
- 同一发布组件使用两次，拥有两份独立覆盖；发布源不变。锁定的另一实例保留原尺寸与位置。
- 普通阵列先按原数量展开成稳定 ID（`成员#阵列-序号`）的物理实例，再参与反算。保存原 `patterns` 作为设计来源；几何模式不再次展开普通阵列、不重新套用旧绑定。普通阵列数量的改变属于结构编辑；下述柱片撑杆规则单独支持按高度增删实例。
- 参数页旧绑定编辑路径在几何模式中只读；后台拒绝通过旧绑定参数写入绕过试算。其他几何编辑会使 `verified` 失效。
- 发布、导出、刷新和嵌套预览读取相同的已保存实例结果。新几何模式停止旧浏览器独立重算路径。

## 柱片高度变化时补齐撑杆

在“参数 → 几何联动”中点击“打开柱片调整窗口”：

1. 点击“读取当前实际尺寸”，读取当前柱片高度。
2. 选择“自动补齐横撑、斜撑”。每个柱片模板在制作时即内置规则，撑杆保持原规格与长度，随高度增删，使用时无需配置。旧模板缺少规则时显示制作未完成，须先完成模板升级及验收。
3. 输入目标高度，或点击“拉长/缩短”按钮。窗口保持当前实际 X、Y，只改变 Z；快捷步长为第一套规则的横撑分格，合法性仍由全部规则及真实 CAD 校验。
4. 点击“预览高度调整”，核对新增、移除数量和三维结果，再点击“应用”。关闭或取消不会应用预览。

取消勾选时使用普通几何联动，保留现有撑杆数量，撑杆尺寸与位置继续受已有连接和锁定约束，未必能满足所有目标高度。规则配置保留，应用时保存 `enabled=false`；再次勾选后可按新高度重新补齐。多条根规则统一切换，原先分别设置的启用状态在未操作开关时保持不变。选择与目标高度均在应用时保存，不会在点击勾选时立即修改草稿。

向 AI 说明：“制作柱片模板。高度变化时保持横撑、斜撑规格和长度，按新增真实孔位补齐；缩短时删除多余撑杆。制作过程中验证增高、缩短和重复调整。”

AI 通过 `component_set_brace_generation_rule` 保存 `braceGenerationRules`，读取左右立柱的真实孔列、横撑和斜撑的端口，分别确定孔列模式、编号起点、孔距和跨孔步长。新增孔位来自按新高度实际重建的立柱；撑杆使用固定规格原型，位置和角度随连接求解。每次重建先清理规则生成的旧成员和连接，再补齐目标数量，避免重复累积。

仅要求真实孔位定位时，AI 设置 `connectionMode: "geometry"`，规则生成经 CAD 校验的几何关系，并校验撑杆节点对准孔心，交替斜撑依据真实端口方向放置。需要正式装配连接时设置 `connectionMode: "mates"`，继续检查来源契约、连接关系和接口容量；旧规则默认采用该模式。缺少契约不会自动补造，也不能把几何通过解释为工程配合通过。自动推断的接触会随撑杆增删重新计算；用户明确建立的连接和约束不会为了通过试算被删除，引用被移除撑杆时会要求处理冲突。

1. 在“参数配置”的几何联动中读取实际尺寸，修改 Z 高度，等待真实 CAD 预览。
2. 查看撑杆数量及连接，确认横撑、斜撑的长度和截面保持原规格，点击“应用”保存。
3. 再次缩短或增高，平台按同一规则重新生成；自动制作验收检查当前修订，通过后才能发布。

规则必须明确顶部余量策略。`reject` 只支持“底部余量 + 顶部余量 + 整数个横撑分格”的高度；`top-clearance` 将不足一格的部分留在顶部，不拉伸撑杆凑满。默认验收对 `reject` 选取合法的双向高度，并避开规则明确禁止的孔列边界抽查尺寸。明确填写的使用范围端点和额外目标保持原值，无法完整分格时会报告失败。

斜撑起点高于横撑起点时，从可用高度扣除实际起点偏移，只补齐容得下的整根斜撑。不同孔列依据真实 CAD 孔心坐标计算偏移，不能直接比较编号；交替斜撑按实际左右连接方向检查孔位与余量。无法容纳一根固定斜撑时，报告所需最小高度，不拉伸撑杆凑数。

预览和自动制作验收的分步恢复共用合法分格选择：例如 3000 → 1950 mm、底顶余量合计 300 mm、分格 150 mm 时，中间使用 2400 mm，避免使用不合法的 2475 mm。最终请求仍为 1950 mm。相邻合法高度间没有中间高度时，组合调整可先推进其他方向；仅调整高度则保留原求解错误，不反复尝试非法尺寸。

孔位不足、端口跨度与所选孔位不匹配、来源模板不能生成接口或超出参数范围时，试算会保留原草稿并说明原因。制作时应依据真实模板修正规则或选型，再重新验收；已有模型不会仅因外观相似而自动获得撑杆生成规则。

预览区分别显示已有零件调整数、新增数和移除数，并列出新增/移除成员的名称及路径。调整与新增成员在模型中高亮；已移除成员通过清单确认。任务结果的 `structureChanges.added/removed` 提供相同数据，分步求解时与最初草稿比较，避免只展示最后一步的增删。

锁定在规则生成阶段同样有效。整件锁定保留原位置、角度和全部尺寸；尺寸锁定保留指定参数，允许零件正常移动。新高度要求改变已锁定的立柱长度、或缩短将移除已锁定撑杆时，试算返回 `RESIZE_LOCK_CONFLICT`，说明冲突对象和尺寸，保留草稿。不能用目标高度重设锁定基线，也不会自动解除锁定。CAD 种子放置不覆盖整件锁定的位置。

自动制作验收的构造、孔位物化、求解和边界样本规划均在共享 CAD 队列的后台线程执行，避免构造阶段阻塞 HTTP 状态读取。队列中的取消会退出等待；已进入单次 CAD 内核调用时，仍在该调用结束后检查取消。验收策略升级会使旧证书失效，需按新策略重新验收。

多条撑杆规则可共用立柱，但需使用独立的横撑、斜撑原型成员；同规格原型仍可引用同一发布模板。一个成员不能兼作立柱和撑杆，也不能用本轮将清理的生成实例作为原型。规则编号必须唯一，孔列模式必须含一个 `{index}` 或 `{index:03d}` 编号占位符，补零宽度限 1–10。单独指定的斜撑孔距同样必须引用正数 mm 参数。源码预检查、MCP 写入、页面基础验证和 CAD 生成均有相应检查。

不同撑杆若以相同来源、规格及端口对应关系重复连接同一对立柱接口，生成时返回 `BRACE_RULE_NODE_CONFLICT`，说明两条规则和两根撑杆。只共用孔位、使用不同构件，或反向安装不据此判定实体重复；最终仍需 CAD 定位，正式装配模式另外检查接口容量。生成连接的清理按完整规则标识归属，规则 `a` 不会误删 `a__b` 的连接；`origin=user` 的明确几何约束不因标识类似自动连接而丢失。

前端与后端 JSON 导出均保留生成成员的 `generatedBy`、`generatedIndex`，使按导出字段重新构造的文档仍可在缩短时清理旧撑杆。原有普通成员不新增这些字段。平台不会仅凭相似名称或成员 ID 推断归属，以免把用户零件误当成可删除实例。

## HTTP 和 Agent 接口

| 请求 | 用途 |
| --- | --- |
| `POST /api/component-drafts/{id}/resize-jobs` | `expectedRevision`、`dimensions: [X,Y,Z]`、可选 `design.locks/relations`、`solutionIndex`；`inspectOnly: true` 只读取实际模型 |
| `GET /api/component-drafts/{id}/resize-jobs/{jobId}` | 读取状态、进度、候选、变更、结果文档及校验值 |
| `DELETE /api/component-drafts/{id}/resize-jobs/{jobId}` | 取消，保留原组件 |
| `POST /api/component-drafts/{id}/resize-apply` | `expectedRevision`、`jobId`、`checksum`，原子应用服务器预览 |
| `GET /api/component-drafts/{id}/resize-history` | 获取仍可撤销的上次应用信息 |
| `POST /api/component-drafts/{id}/resize-undo` | 按应用后的版本及原任务校验值整体恢复 |

状态：`running`、`needs_choice`、`ready`、`failed`、`cancelled`、`stale`、`applied`。页面与 MCP 的 `component_resize_preview/status/cancel/apply/undo` 使用同一服务。几何模式下 Agent 应使用这些接口调整尺寸。

新任务使同一草稿旧预览失效。前端还使用请求代次阻止迟到响应覆盖新输入。应用必须匹配草稿修订和预览校验值，SQLite 事务同时写完整结果、一次修订及撤销记录。另一页面或 Agent 修改后，旧预览不能应用，也不能用旧撤销覆盖新修改。

试算任务暂存于服务内存（最多 100 项，完成后保留 30 分钟）；服务重启需重新试算。上次应用前状态保存在 SQLite，刷新和服务重启后仍可恢复，前提是之后没有新修订。

## 测试和边界

```powershell
npm test
npm run build
.venv/Scripts/python.exe -m unittest discover -s backend/tests -v
```

- `test_geometry_resize.py`：真实 OCCT 简单实体、接口链、旋转实例、锁定另一实例、阵列、超限、离散多解、接口消失、取消、原子修订和导出。
- `test_geometry_resize_cad.py`：固定的立柱、横撑、斜撑、矩管、端板和角铁模板；柱片加宽/加高、横梁含端板外形、支撑框接触、三层旋转重复子组件及重新读取的一致性。测试使用仓库内夹具，不改用户草稿。
- `test_geometry_resize_api.py`：完整 HTTP 任务流程、校验值错误、连续请求、并发修改、取消、失败、发布内容与导出、服务任务丢失后的持久撤销。
- `geometry-resize.test.mjs`：阻止旧绑定覆盖、阵列不重复展开、前端导出、多实例隔离。

页面验收在隔离数据库中执行：读取实际尺寸 → 修改目标 → 等待模型 → 应用 → 刷新 → 恢复，检查草稿修订、完整成员数据和浏览器运行错误。不得用用户正在编辑的草稿做写入式测试。

支持具有可解析 CAD 来源和可调尺寸的上述零件及多层组合。未知语义面、无法唯一恢复的曲面/轴线、未开放参数或不明确的结构意图需要补充信息。组件文字规则仅作说明；几何验证不涵盖载荷、焊缝和完整制造检查。

## 柱片模板的内置补齐交付要求

柱片由名称、分类或双立柱及横撑/斜撑结构识别。创建草稿时允许逐步制作，但缺少补齐规则、存在未纳入规则的立柱或撑杆、两侧立柱未绑定规则高度时，制作检查失败，不能取得交付证书或发布。嵌套柱片同样检查。关闭自动补齐仅保存使用偏好，不免除模板能力要求。

AI 制作要求默认包含该能力，无需用户每次提醒。制作验收额外在副本中启用规则，验证原尺寸、增高和缩短时真实孔位与固定撑杆规格，试算不覆盖原高度或开关。旧模板不能仅凭零件名称自动认定实例归属；升级时确认真实 CAD、同一来源与规格及全部外部引用，保留锁定与用户约束。
